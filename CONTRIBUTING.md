# Guía de contribución

¡Gracias por querer contribuir a este libro! Aquí tienes las pautas básicas.

## Cómo reportar un error

Abre un [issue](https://github.com/urukaisk-maker/Libro-desarrollador-Web-Urukais-/issues/new) describiendo:

- Qué capítulo o archivo.
- Qué esperabas encontrar.
- Qué encontraste en su lugar.

## Cómo proponer una mejora

1. Haz un fork del repositorio.
2. Crea una rama: `git checkout -b mejora/nombre-corto`
3. Haz tus cambios.
4. Commitea con mensajes claros: `docs: corregir errata en capítulo 1`
5. Abre un Pull Request.

## Estilo de escritura

- Markdown limpio, sin HTML embebido salvo que sea necesario.
- Títulos en sentence case (`## Cómo usar este repositorio`).
- Ejemplos ejecutables y autocontenidos.
- Enlaces relativos entre capítulos.

## Código de conducta

Sé respetuoso. No se tolerará ningún tipo de acoso o descalificación.
