    📚 Libros recomendados¶

    Estos son los libros que más han influido en mi forma de programar y enseñar:

    Fundamentos¶

    Libro Autor Nivel Por qué leerlo
    HTML and CSS: Design and Build Websites Jon Duckett 🟢 Principiante El libro más visual y accesible para empezar.
    Eloquent JavaScript Marijn Haverbeke 🟡 Intermedio JavaScript explicado con elegancia. Gratis online.
    You Don't Know JS (serie) Kyle Simpson 🟠 Avanzado Para entender JS de verdad. Gratis en GitHub.
    CSS: The Definitive Guide Eric A. Meyer 🟠 Avanzado La biblia del CSS.

    Arquitectura y buenas prácticas¶

    Libro Autor Nivel Por qué leerlo
    Clean Code Robert C. Martin 🟠 Avanzado Buenas prácticas de código limpio.
    Refactoring Martin Fowler 🔴 Profesional Cómo mejorar código existente sin romperlo.
    Designing Data-Intensive Applications Martin Kleppmann 🔴 Profesional La biblia de los sistemas distribuidos.
    The Pragmatic Programmer Hunt & Thomas 🟡 Intermedio El libro que más he regalado. Enseña a pensar como programador.

    Diseño y UX¶

    Libro Autor Nivel Por qué leerlo
    Refactoring UI Adam Wathan & Steve Schoger 🟡 Intermedio Cómo hacer que tus interfaces se vean profesionales.
    Don't Make Me Think Steve Krug 🟡 Intermedio Los principios de la usabilidad explicados con humor.
    Design Systems Alla Kholmatova 🟣 Experto Cómo construir sistemas de diseño escalables.

    🛠️ Herramientas imprescindibles¶

    Editores de código¶

    Herramienta Plataforma Por qué usarla
    VS Code Win/Mac/Linux El más popular. Extensiones para todo.
    Zed Mac/Linux Ultrarrápido, escrito en Rust.
    WebStorm Win/Mac/Linux El más potente (de pago, con versión gratis para estudiantes).
    Neovim Terminal Para quienes quieren control total.

    Navegadores y DevTools¶

    Herramienta Por qué usarla
    Chrome DevTools Las DevTools más completas.
    Firefox Developer Edition Excelente para CSS y accesibilidad.
    Polypane Navegador para desarrollo responsive (de pago).

    Diseño¶

    Herramienta Por qué usarla
    Figma Diseño colaborativo en el navegador.
    Excalidraw Diagramas rápidos estilo pizarra.
    Coolors Generador de paletas de colores.
    Google Fonts Tipografías gratuitas.

    Testing y calidad¶

    Herramienta Por qué usarla
    Vitest Testing ultrarrápido para Vite.
    Jest El estándar de testing en JS.
    Playwright Testing E2E en todos los navegadores.
    ESLint Linter para JavaScript y TypeScript.
    Prettier Formateador de código.

    Despliegue¶

    Herramienta Por qué usarla
    Netlify Despliegue con un git push.
    Vercel Ideal para Next.js y frontend moderno.
    GitHub Pages Gratis para proyectos open source.
    Cloudflare Pages CDN global gratuita.

    💡 Cómo usar estos recursos¶

    No te disperses

    Con tantos recursos, es fácil caer en la parálisis por análisis. Mi consejo:

    1. Elige un recurso por categoría (un libro, un canal, una documentación).
    2. Termínalo antes de empezar otro.
    3. Practica con proyectos propios, no solo consumas contenido.
    4. No acumules cursos: es mejor terminar uno que empezar diez.

    ¿Falta algún recurso?

    Si conoces un recurso que debería estar aquí, abre un issue en GitHub o envía un PR. Los recursos se revisan cada semana.
