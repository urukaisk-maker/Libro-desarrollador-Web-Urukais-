## 📖 Glosario exprés

??? question "¿Qué es una API?"
    **Application Programming Interface**. Un conjunto de reglas que permite que dos programas se comuniquen entre sí. En desarrollo web, casi siempre se refiere a una **API REST** o **GraphQL** que devuelve datos en JSON.

??? question "¿Qué es el DOM?"
    **Document Object Model**. La representación en forma de árbol del documento HTML que el navegador construye en memoria. JavaScript puede leerlo y modificarlo para hacer la página interactiva.

??? question "¿Qué es un bundler?"
    Una herramienta que **empaqueta** todos los archivos de tu proyecto en unos pocos archivos optimizados. Ejemplos: **Vite**, **Webpack**, **esbuild**, **Rollup**.

??? question "¿Qué es una PWA?"
    **Progressive Web App**. Una web que se comporta como una app nativa: se puede instalar, funciona offline y envía notificaciones push.

??? question "¿Qué es el event loop?"
    El mecanismo que permite a JavaScript (de un solo hilo) gestionar operaciones asíncronas. Coordina la **pila de llamadas**, la **cola de tareas** y la **cola de microtareas**.
