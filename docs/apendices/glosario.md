# Glosario

Términos esenciales del desarrollo web, ordenados alfabéticamente.

## A

**API** — *Application Programming Interface*. Conjunto de reglas que permite a dos programas comunicarse.

**Async/await** — Sintaxis moderna de JavaScript para manejar operaciones asíncronas de forma legible.

## B

**Backend** — Parte del desarrollo web que corre en el servidor (lógica, base de datos).

**Branch (rama)** — Línea de desarrollo independiente dentro de un repositorio Git.

## C

**CDN** — *Content Delivery Network*. Red de servidores distribuidos que sirven archivos estáticos rápido.

**Commit** — Registro de un cambio en el historial de Git.

**CSS** — *Cascading Style Sheets*. Lenguaje que define la presentación de una página.

## D

**DOM** — *Document Object Model*. Representación en memoria del HTML, manipulable con JavaScript.

**Deploy** — Publicar una aplicación en internet.

## F

**Fetch** — API del navegador para hacer peticiones HTTP.

**Flexbox** — Modelo de layout CSS unidimensional.

**Frontend** — Parte del desarrollo web que corre en el navegador.

## G

**Git** — Sistema de control de versiones distribuido.

**GitHub** — Plataforma para alojar repositorios Git.

**Grid** — Modelo de layout CSS bidimensional.

## H

**HTML** — *HyperText Markup Language*. Lenguaje de marcado que define la estructura de la web.

**HTTP** — Protocolo de transferencia de hipertexto.

## J

**JavaScript** — Lenguaje de programación que corre en el navegador (y también en Node.js).

**JSON** — *JavaScript Object Notation*. Formato de intercambio de datos.

## M

**Markdown** — Lenguaje de marcado ligero para escribir documentación.

**Media query** — Regla CSS que aplica estilos según el tamaño de pantalla.

## N

**Node.js** — Entorno que permite ejecutar JavaScript fuera del navegador.

## P

**PNG / JPG / SVG / WebP** — Formatos de imagen. SVG es vectorial; los demás son mapas de bits.

**Pull request** — Propuesta de fusionar cambios en GitHub.

## R

**Responsive** — Diseño que se adapta a cualquier tamaño de pantalla.

**REST** — Estilo arquitectónico para APIs basadas en HTTP.

## S

**SCSS / Sass** — Preprocesador de CSS con variables, anidamiento y funciones.

**SEO** — *Search Engine Optimization*. Optimización para buscadores.

## T

**Terminal** — Interfaz de línea de comandos.

**TypeScript** — JavaScript con tipos estáticos.

## V

**Viewport** — Área visible de la página en el dispositivo.

## W

**Webpack / Vite** — Empaquetadores de módulos para frontend.
