# Recursos por nivel

Qué estudiar después según tu punto de partida.

## 🌱 Principiante (acabas de empezar)

- Termina los capítulos 1 a 6 de este libro.
- Practica con [freeCodeCamp](https://www.freecodecamp.org/espanol/).
- Recrea páginas simples que te gusten (una tarjeta, un menú, un footer).
- Aprende a usar el navegador: DevTools, consola, inspector.

**Objetivo**: construir una web estática de 3–4 páginas.

## 🌿 Intermedio (ya manejas HTML/CSS/JS básicos)

- Domina **Flexbox** y **Grid** con [Flexbox Froggy](https://flexboxfroggy.com/#es) y [Grid Garden](https://cssgridgarden.com/#es).
- Aprende **SCSS** o **Tailwind CSS**.
- Practica JavaScript moderno (ES6+): `map`, `filter`, `async/await`.
- Aprende **Git** en serio: ramas, merge, rebase.
- Empieza con un framework: [React](https://react.dev/), [Vue](https://vuejs.org/) o [Svelte](https://svelte.dev/).

**Objetivo**: desplegar tu portfolio con proyectos reales.

## 🌳 Avanzado

- **TypeScript** — tipado estático para JavaScript.
- **Testing** — Vitest, Jest, Playwright.
- **Backend** — Node.js, Express, bases de datos (PostgreSQL, MongoDB).
- **APIs REST y GraphQL**.
- **Docker** y despliegue en la nube (Vercel, Railway, Fly.io).
- **Accesibilidad** (WCAG, ARIA) y **rendimiento** (Core Web Vitals).

**Objetivo**: contribuir a proyectos open source, trabajar en equipo, especializarte.

## 🎯 Consejos finales

1. **Construye proyectos reales** — la teoría sola no basta.
2. **Lee código ajeno** — GitHub está lleno de ejemplos.
3. **Contribuye a open source** — empieza con documentación, luego con código.
4. **Comparte lo que aprendes** — blog, Twitter/X, charlas.
5. **No te compares** — cada persona tiene su ritmo.
