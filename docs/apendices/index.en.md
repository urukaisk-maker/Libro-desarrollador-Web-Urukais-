## 📖 Express Glossary

??? question "What is an API?"
    **Application Programming Interface**. A set of rules that lets two programs communicate with each other. In web development, it almost always refers to a **REST API** or **GraphQL** returning JSON data.

??? question "What is the DOM?"
    **Document Object Model**. The tree-like representation of the HTML document built in memory by the browser. JavaScript can read and modify it to make the page interactive.

??? question "What is a bundler?"
    A tool that **packages** all the files in your project into a few optimized bundles. Examples: **Vite**, **Webpack**, **esbuild**, **Rollup**.

??? question "What is a PWA?"
    **Progressive Web App**. A web app that behaves like a native app: installable, works offline, and sends push notifications.

??? question "What is the event loop?"
    The mechanism that allows single-threaded JavaScript to handle asynchronous operations. It coordinates the **call stack**, the **task queue**, and the **microtask queue**.
