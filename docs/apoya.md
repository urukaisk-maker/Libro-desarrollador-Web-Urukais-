# ❤️ Apoya el Proyecto

!!! quote "El libro es gratis. Siempre lo será."
    Este proyecto no tiene publicidad, ni suscripciones, ni muros de pago. Todo el contenido es accesible para cualquiera, independientemente de su situación económica. Pero mantenerlo lleva tiempo y esfuerzo. Si te resulta útil, aquí tienes formas de apoyarlo.

---

## 🎯 ¿Por qué apoyar el proyecto?

Este libro nació de una frustración: la falta de material de calidad en español para aprender desarrollo web. Lo que empezó como apuntes personales se ha convertido en un recurso que leen miles de personas cada mes.

Mantenerlo requiere:

- **Tiempo**: escribir, revisar y actualizar capítulos.
- **Infraestructura**: aunque GitHub Pages es gratis, hay servicios externos (dominio, analíticas, etc.).
- **Herramientas**: editores, tipografías, servicios de email.
- **Café**: mucho café. ☕

!!! info "El apoyo es opcional"
    Nada de lo que hay en esta página es obligatorio. El libro seguirá siendo gratis y completo, tanto si apoyas como si no. Si no puedes o no quieres aportar nada económico, **no pasa nada**. Hay muchas otras formas de ayudar (las tienes más abajo).

## 📊 ¿En qué se usa el dinero?

Transparencia total. Esto es en lo que se gasta (o se gastaría) el apoyo económico:

| Categoría | Porcentaje | Detalle |
| :--- | :--- | :--- |
| ☕ **Tiempo del autor** | 60% | Dedicar más horas al proyecto |
| 🌐 **Infraestructura** | 20% | Dominio, servicios externos, herramientas |
| 🎨 **Diseño y recursos** | 10% | Tipografías, iconos, imágenes de stock |
| 🎁 **Sorteos y comunidad** | 10% | Libros, cursos, merchandising para lectores |

    Si el proyecto recibe apoyo económico significativo, publicaré un informe trimestral con el desglose exacto. Mientras tanto, todo lo que entra se reinvierte en el proyecto.

## ❓ Preguntas frecuentes

??? question "¿Es obligatorio apoyar?"
    **No.** El libro es gratis y siempre lo será. El apoyo es completamente opcional. Si no puedes o no quieres aportar nada, no pasa nada: el libro sigue siendo para ti.

??? question "¿Puedo apoyar de forma anónima?"
    **Sí.** Tanto Buy Me a Coffee como Substack permiten hacer aportaciones anónimas. Si quieres que tu nombre aparezca en la lista de agradecimientos, dínoslo.

??? question "¿Hay contenido premium?"
    **No.** Ninguna suscripción desbloquea contenido extra. El libro es el mismo para todos. Si alguien te ofrece una "versión premium", es un fraude.

??? question "¿Puedo donar de otra forma?"
    Si prefieres otra forma de apoyo (transferencia, criptomonedas, etc.), escríbeme a [contacto@urukais.com](mailto:contacto@urukais.com) y buscamos una solución.

??? question "¿Puedo patrocinar el proyecto con mi empresa?"
    **Sí.** Escríbeme a [contacto@urukais.com](mailto:contacto@urukais.com) con el asunto "Patrocinio" y te cuento las condiciones.

??? question "¿Qué pasa si el proyecto deja de existir?"
    Si algún día decido dejar el proyecto, el contenido seguirá disponible en GitHub bajo licencia MIT. Cualquiera podrá hacer un fork y continuarlo. El conocimiento no se pierde.
