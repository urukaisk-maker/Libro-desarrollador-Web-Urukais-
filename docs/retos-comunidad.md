# 🏆 Retos de la Comunidad

Aquí publicamos los **Retos del Mes**. Cualquier persona puede enviar su solución a través de un Pull Request en GitHub. Las mejores se mostrarán en el Muro de Soluciones.

## 🔥 Reto del Mes

### 💡 Reto: "Tu propio componente de tarjeta de producto"

**Objetivo:** Crear un componente de tarjeta de producto que muestre imagen, título, precio y un botón de "Añadir al carrito". Debe ser responsive y accesible.

**Requisitos:**
- HTML semántico.
- CSS con Grid o Flexbox.
- JavaScript para el botón (puede ser un simple `alert()` o un contador).

**Cómo participar:**
1. Haz un fork del [repositorio del libro](https://github.com/urukaisk-maker/Libro-desarrollador-Web-Urukais-).
2. Crea una rama con tu nombre y el reto: `git checkout -b reto-mes/tu-nombre`.
3. Añade tu solución en `docs/retos/comunidad/tu-nombre.md`.
4. Abre un Pull Request con una descripción.
5. Si tu solución es elegida, aparecerá en el Muro de Soluciones y en la página principal del libro.
