# 🔀 Git & GitHub — Immersive Experience

!!! abstract "🖥 From beginner to master"
    **Level:** 🟠 Advanced · **Author:** @urukaisk

    An immersive experience for learning Git and GitHub with a **futuristic interface**, Matrix background video, neon effects, and interactive demos in a simulated terminal.

## 🎯 What you will find

- 💻 **Simulated terminal** with real commands (`git init`, `git commit`, etc.).
- 🎬 **Matrix video** background.
- ✨ **Neon** effects and smooth transitions.
- 🎓 10-day visual course: from beginner to version control master.
- 🧪 **Interactive demos**.

## 🛠 Technologies

`HTML5` · `Advanced CSS3 (animations)` · `JavaScript` · `Netlify`
