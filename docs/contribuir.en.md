# 🤝 How to Contribute

!!! quote "This book belongs to everyone"
    The **Web Developer's Book** is an open-source project. That means **you can be part of it too**, even if you don't know how to code yet. There are many ways to help, and every single one counts.

---

## 🌟 Why Contribute?

Contributing to an open-source project comes with plenty of benefits:

| Benefit | Why It Matters |
| :--- | :--- |
| **Learn by doing** | Reading other people's code and proposing improvements is one of the best ways to grow as a developer. |
| **Add experience to your résumé** | Open-source contributions are publicly visible and highly valued in interviews. |
| **Meet people** | This project's community is made up of people who share your interests. |
| **Improve the book** | Every fix, suggestion, or translation helps thousands of readers. |
| **Get credited in acknowledgments** | Everyone who contributes is listed on the [Acknowledgments](agradecimientos.md) page. |

!!! tip "You don't need to be an expert"
    Many of the most valuable contributions come from people who **are actively learning**. A beginner spots clarity gaps that an expert easily overlooks.

---

## 🎯 Ways to Contribute

### 1. Report a Bug 🐛

If you spot a broken link, a typo, code that doesn't work, or a confusing explanation:

1. **Search first** to see if an issue is already open:
   [Project Issues](https://github.com/urukaisk-maker/Libro-desarrollador-Web-Urukais-/issues)
2. If not, **open a new one**:
   [New Issue](https://github.com/urukaisk-maker/Libro-desarrollador-Web-Urukais-/issues/new)
3. Fill out the template with:
   - **Expected behavior**
   - **Actual behavior**
   - **Steps to reproduce** (screenshot, URL, code…)
   - **Your environment** (browser, operating system…)

!!! example "Bug issue template"
    ```markdown
    **Description**
    When copying the code from Chapter 03, the page doesn't show the expected blue color.

    **How to reproduce**
    1. Go to `[https://libro.urukais.com/capitulos/03-css-basico/](https://libro.urukais.com/capitulos/03-css-basico/)`
    2. Copy the example from the "Colors" block
    3. Paste it into an HTML file
    4. Open it in the browser

    **Expected**
    The text should be blue (`#00bcd4`).

    **Actual**
    The text renders in black.

    **Environment**
    - Browser: Firefox 121
    - OS: Garuda Linux
    ```
