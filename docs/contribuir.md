# 🤝 Cómo contribuir

!!! quote "Este libro es de todos"
    El **Libro del Desarrollador Web** es un proyecto open source. Eso significa que **tú también puedes formar parte de él**, aunque no sepas programar. Hay muchas formas de ayudar, y todas cuentan.

---

## 🌟 ¿Por qué contribuir?

Contribuir a un proyecto open source tiene muchos beneficios:

| Beneficio | Por qué importa |
| :--- | :--- |
| **Aprendes haciendo** | Leer código ajeno y proponer mejoras es una de las mejores formas de crecer como desarrollador. |
| **Añades experiencia a tu CV** | Las contribuciones a proyectos open source son visibles públicamente y muy valoradas en entrevistas. |
| **Conoces gente** | La comunidad de este proyecto está formada por personas que comparten tus intereses. |
| **Mejoras el libro** | Cada corrección, sugerencia o traducción beneficia a miles de lectores. |
| **Apareces en los agradecimientos** | Todas las personas que contribuyen aparecen en la página de [Agradecimientos](agradecimientos.md). |

!!! tip "No hace falta ser experto"
    Muchas de las contribuciones más valiosas son de personas que **están aprendiendo**. Un principiante detecta fallos de claridad que un experto pasa por alto.

---

## 🎯 Formas de contribuir

### 1. Reportar un error 🐛

Si encuentras un enlace roto, una errata, un código que no funciona o una explicación confusa:

1. **Busca primero** si ya existe un issue abierto:
   [Issues del proyecto](https://github.com/urukaisk-maker/Libro-desarrollador-Web-Urukais-/issues)
2. Si no existe, **abre uno nuevo**:
   [Nuevo issue](https://github.com/urukaisk-maker/Libro-desarrollador-Web-Urukais-/issues/new)
3. Rellena la plantilla con:
   - **Qué esperabas** que pasara
   - **Qué pasó realmente**
   - **Cómo reproducirlo** (captura, URL, código…)
   - **Tu entorno** (navegador, sistema operativo…)

    ```markdown
    **Descripción**
    Al copiar el código del capítulo 03, la página no muestra el color azul esperado.

    2. Copiar el ejemplo del bloque "Colors"

    4. Abrir en el navegador

    **Esperado**
    El texto debería ser azul (`#00bcd4`).

    **Real**
    El texto aparece negro.

    **Entorno**
    - Navegador: Firefox 121
    - Sistema: Garuda Linux
