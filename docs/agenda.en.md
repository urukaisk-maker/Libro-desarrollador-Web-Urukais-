## 🎤 Want me to give a talk or workshop?

If you are organizing a meetup, conference, or workshop and would like me to join, email me at [contacto@urukais.com](mailto:contacto@urukais.com) with the details:

- **Event**: name and topic
- **Format**: talk, workshop, panel…
- **Duration**: 20 min, 1 h, 2 h…
- **Target audience**: beginners, intermediate, experts
- **Date and location**: in-person or online
- **Budget**: if available, to cover travel expenses

!!! tip "Topics I can speak about"
    - Web fundamentals (HTML, CSS, JavaScript)
    - Modern JavaScript (ES6+, async/await, event loop)
    - Web accessibility from scratch
    - Frontend architecture
    - How to create an open-source book (my experience building this project)

## 🎯 Want to propose an event?

If you have an idea for a workshop, livestream, or talk, you can propose it:

1. **Open an issue** on GitHub with the `evento` label:
   [Propose an event](https://github.com/urukaisk-maker/Libro-desarrollador-Web-Urukais-/issues/new)
2. **Fill out the template** with:
   - Event title
   - Short description
   - Format (online/in-person)
   - Target audience
   - Proposed date
   - Whether you need collaborators or resources

Proposed events are reviewed every week. If they fit the project, they get added to the agenda.

## ❓ Frequently asked questions

??? question "Are events free?"
    **Yes, all events are free.** There are no paid events or "premium versions" of workshops. If a paid event ever happens (for example, an in-person workshop with physical materials), it will be clearly stated.

??? question "What do I need to attend a workshop?"
    It depends on the workshop. For online workshops, all you need is a browser and curiosity to learn. For in-person sessions, requirements are listed in the event description.

??? question "Are events recorded?"
    **Yes, most of them.** Workshops and talks are recorded and published on YouTube so you can watch them anytime. Twitch livestreams stay on the channel for a limited time.

??? question "Can I suggest a workshop topic?"
    **Yes.** Open an issue with the `evento` label and let us know what topic interests you. If there is enough demand, it will be scheduled.

??? question "How do I stay updated on new events?"
    - **Newsletter**: subscribe on [Substack](https://urukaisklick.substack.com).
    - **Twitter / X**: follow [@urukaisk](https://twitter.com/urukaisk).
    - **GitHub**: watch issues with the `evento` label.
