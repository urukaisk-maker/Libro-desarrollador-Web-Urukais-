## 🎤 Want Me to Give a Talk or Workshop?

If you're organizing a meetup, conference, or workshop and would like me to join, email me at [contacto@urukais.com](mailto:contacto@urukais.com) with the details:

- **Event**: name and topic
- **Format**: talk, workshop, panel…
- **Duration**: 20 min, 1 hr, 2 hrs…
- **Target audience**: beginners, intermediate, experts
- **Date and location**: in-person or online
- **Budget**: if available, to cover travel expenses

!!! tip "Topics I can speak about"
    - Web fundamentals (HTML, CSS, JavaScript)
    - Modern JavaScript (ES6+, async/await, event loop)
    - Web accessibility from scratch
    - Frontend architecture
    - How to create an open-source book (my experience with this project)

## 🎯 Want to Propose an Event?

If you have an idea for a workshop, livestream, or talk, you can propose it:

1. **Open an issue** on GitHub with the `evento` label:
   [Propose event](https://github.com/urukaisk-maker/Libro-desarrollador-Web-Urukais-/issues/new)
2. **Fill out the template** with:
   - Event title
   - Short description
   - Format (online/in-person)
   - Target audience
   - Proposed date
   - Whether you need collaboration or resources

Proposed events are reviewed every week. If they fit the project, they get added to the schedule.

## ❓ Frequently Asked Questions

??? question "Are events free?"
    **Yes, all events are free.** There are no paid events or "premium versions" of workshops. If an event ever has a cost (for instance, an in-person workshop with materials), it will be clearly stated.

??? question "What do I need to attend a workshop?"
    It depends on the workshop. For online workshops, you just need a browser and eagerness to learn. For in-person events, requirements are noted in the event description.

??? question "Are events recorded?"
    **Yes, most of them.** Workshops and talks are recorded and published on YouTube so you can watch them anytime. Twitch livestreams stay on the channel for a limited time.

??? question "Can I suggest a workshop topic?"
    **Yes.** Open an issue with the `evento` label and let us know what topic interests you. If there's enough demand, it gets scheduled.

??? question "How do I find out about new events?"
    - **Newsletter**: subscribe on [Substack](https://urukaisklick.substack.com).
    - **Twitter / X**: follow [@urukaisk](https://twitter.com/urukaisk).
    - **GitHub**: watch issues with the `evento` label.
