## 🏠 About the project

??? question "What exactly is the Web Developer Book?"
    It is a **free and open-source educational resource** that teaches web development from scratch to an advanced level. It is organized into **7 levels** and **38 chapters**, and includes theory, runnable examples, solved exercises, interactive quizzes, and an achievement system.

    It is not a paid course or a subscription platform: it is an open book that you can read, copy, and reuse freely.

??? question "Who is behind the project?"
    The project is maintained by **Manuel Casimiro Carrasco (Urukais)**, web developer and technical educator. You can learn more on the [About the author](autor.md) page.

??? question "Why is it free?"
    Because when I started learning, there was nothing like this in Spanish that wasn't a paid course or a machine translation. I wanted anyone, regardless of their financial situation, to be able to learn to code. The book has no ads, no affiliates, and no paywalls. If you want to [support the project](apoya.md), you can, though it is completely optional.

??? question "How is it funded?"
    **With the author's free time and community support.** The infrastructure (GitHub Pages, GitHub Actions) is free. Any income from [Substack](https://urukaisklick.substack.com) or [support](apoya.md) goes back into the project or is appreciated as a coffee.

??? question "How long has it been published?"
    The project launched publicly in **October 2026**. Since then, it has been updated regularly with new chapters, design improvements, and extra resources.

??? question "Does it have an end date?"
    **No.** The project is a marathon, not a sprint. Chapters are published when they are ready, not on a rushed schedule. I prefer one well-written chapter a month over a mediocre one every week.

## 📚 About the content

??? question "Who is this book for?"
    Mainly for **three profiles**:

    - **Absolute beginners**: people who have never written a line of code.
    - **Students and self-learners**: looking for structured reference material.
    - **Professionals in transition**: who already code and want to go deeper or get up to speed.

    It is not a book for experts looking for hyper-niche topics; even though higher levels cover advanced subjects, the approach is pedagogical and progressive.

??? question "In what order should I read the chapters?"
    **In order**, especially if you are starting out. Each chapter builds on the previous one. If you already have experience, you can jump straight to the matching level using the **🗂 Explore** button in the top navigation.

??? question "How is it different from other books or courses?"
    Three things:

    1. **It is written natively, not machine-translated.**
    2. **It is free and open source**, with no ads or subscriptions.
    3. **It includes interactive tools** (quizzes, live editors, achievement system) that other resources lack.

??? question "Can I use the content for teaching classes?"
    **Yes**, as long as you keep attribution and do not sell it as your own. The MIT license lets you use, copy, and modify the content. If you want, [send me a message](contacto.md) to tell me how you use it—I would love to know.

??? question "Is the content kept up to date?"
    **Yes.** The book is reviewed periodically to reflect changes in the ecosystem. You can check updates in the [Changelog](changelog.md). If you spot something outdated, [open an issue](https://github.com/urukaisk-maker/Libro-desarrollador-Web-Urukais-/issues/new).

??? question "Does it cover frameworks like React, Vue, or Angular?"
    It covers the **fundamentals** (HTML, CSS, JavaScript) and the concepts **behind** frameworks. It does not dive deep into any specific framework because frameworks come and go, whereas fundamentals stay.

    In the [Advanced Level](capitulos/11-css-moderno.md) there are chapters on modules, bundlers, and architecture that prepare you to pick up any framework afterward.

??? question "Does it include backend?"
    **Yes.** The [Professional Level](capitulos/19-fullstack-node.md) covers Full-stack with Node.js and Frontend DevOps. It is not a frontend-only book.

??? question "Does it have exercises and projects?"
    **Yes.** Every chapter includes:

    - Runnable examples
    - Practice exercises
    - An interactive quiz
    - In some cases, a guided project

    In addition, there is a [Solved exercises](ejercicios/index.md) section with over 30 annotated solutions.

## 🛠 About the technology

??? question "Can I follow along without installing anything?"
    **Yes**, the early chapters can be followed right in the browser using the live editors on each page. Only when you reach Node.js or backend topics will you need to install tools on your machine.

??? question "Which code editor do you recommend?"
    [**VS Code**](https://code.visualstudio.com/) is the most popular and the one I use in examples. You can also try [**Zed**](https://zed.dev/), [**Sublime Text**](https://www.sublimetext.com/), or [**Neovim**](https://neovim.io/) if you prefer something lighter or more configurable.

??? question "Does it work on Windows, macOS, and Linux?"
    **Yes.** The book is a website, so it runs on any operating system. Terminal commands are geared toward **Linux/macOS** (since they are most common in web development), while on Windows you can use **WSL** or **PowerShell** with minor adjustments.

??? question "Do I need a powerful computer?"
    **No.** For 90% of the book, any computer from the last 10 years will do. Only for Docker and certain backend tools will you need at least 8 GB of RAM.

??? question "Can I use a phone or tablet?"
    **Yes**, the site is responsive and works on any device. However, for coding, a physical keyboard is strongly recommended.

??? question "Which browser do I need?"
    Any modern browser: up-to-date **Chrome, Firefox, Edge, or Safari**. It does not work in Internet Explorer (and shouldn't).

## 🎓 About learning

??? question "How long does it take to finish the book?"
    It depends on your pace and prior experience. As a rough guide:

    - **Full dedication** (4–6 h/day): 3–4 months
    - **Steady pace** (1–2 h/day): 8–12 months
    - **Casual pace** (2–3 h/week): 2–3 years

    Speed matters less than consistency.

??? question "Do I need to know math?"
    **No**, for 95% of the book you do not need math beyond the basics. Only in a few advanced topics (WebGL, cryptography, WebAssembly) do math concepts come up, and they are explained from scratch.

??? question "Do I need to know English?"
    **Not strictly required**, but **strongly recommended**. Most technical documentation, articles, and Stack Overflow answers are in English. English terms in the book are explained, yet as you progress you will need to read English docs.

    > *"English is the lingua franca of programming. You don't need to speak it fluently, but you do need to read it."*

??? question "Can I learn to code using only this book?"
    **Yes, with a caveat.** The book gives you the theory, examples, and exercises. But **learning to program requires practice**: building your own projects, making mistakes, looking up fixes, and reading other people's code. The book is a guide, not a shortcut.

??? question "How do I know I am making progress?"
    - **Achievement system**: every completed chapter unlocks a badge.
    - **Quizzes**: at the end of each chapter, you test what you learned.
    - **Solved exercises**: you compare your solution with the provided one.
    - **Your own projects**: the best sign of progress is building something on your own without following a step-by-step tutorial.

??? question "What should I do if I get stuck?"
    1. **Reread** the chapter calmly.
    2. **Search** the error on Google or [Stack Overflow](https://stackoverflow.com/).
    3. **Ask** the community in [GitHub Discussions](https://github.com/urukaisk-maker/Libro-desarrollador-Web-Urukais-/discussions).
    4. **Take a break**: stepping away from the problem for 10 minutes is often the best fix.

    !!! tip "Tip"
        When you get stuck, try explaining the problem out loud (or in writing). **Rubber duck debugging** works: walking through the problem often leads straight to the solution.

??? question "How can I practice more?"
    - Do the exercises in each chapter.
    - Tackle the [weekly challenges](retos.md).
    - Build your own projects (a portfolio, a to-do list, a blog…).
    - Contribute to open-source projects (including this one).
    - Read other developers' code on GitHub.

## 🏆 About achievements and the certificate

??? question "How does the achievement system work?"
    Each time you complete a chapter, check the box at the bottom of the page. A badge unlocks and is stored in your browser via `localStorage`. You can view your achievements on the [My Achievements](logros.md) page.

??? question "Are achievements stored on a server?"
    **No.** Everything is saved **in your browser**. Nothing is sent to any server. Clearing your browser data will erase your achievements.

??? question "Can I sync achievements across devices?"
    **Not yet.** It is on the [Roadmap](roadmap.md), but it requires an authentication system that is not implemented yet.

??? question "Is the certificate officially valid?"
    **No.** The certificate is a **symbolic recognition** that you completed the book. It carries no official academic or professional accreditation. However, you can include it in your portfolio or LinkedIn profile as evidence of self-directed study.

??? question "How do I get the certificate?"
    Once you finish all chapters in the book, the option to generate your certificate unlocks on the [Certificate](certificado.md) page. You can download it as a PDF with your name and completion date.

## 🤝 About contributing

??? question "Can I contribute if I do not know how to code?"
    **Yes.** There are plenty of ways to contribute without writing code: reporting typos, suggesting improvements, sharing the book, translating passages. Everything helps. Full details are on the [Contribute](contribuir.md) page.

## 🌐 About the website

??? question "Why does the site sometimes take a moment to load?"
    The first load can take a couple of seconds while fonts, styles, and scripts are fetched. After that, navigation is instant thanks to Material's prefetching.

??? question "Does it work offline?"
    **Partially.** The book is configured as a **PWA** (Progressive Web App), so once you visit it, some pages are cached and readable offline. Not all features are available offline, though.

??? question "Can I read the book on a Kindle or e-reader?"
    **Yes**, using the [printable version](../print_page/) you can generate a PDF or EPUB to send to your e-reader. Keep in mind that quizzes and live editors will not work on an e-reader.

??? question "Is there a PDF version?"
    **Yes.** You can generate the printable version from the [Printable version](../print_page/) link, which bundles all chapters sequentially on a single page. From your browser you can save it as a PDF.

??? question "How do I report a website issue?"
    If something looks off (a broken link, a layout glitch, a console error), open an [issue on GitHub](https://github.com/urukaisk-maker/Libro-desarrollador-Web-Urukais-/issues/new) with:

    - The page URL
    - A screenshot
    - Your browser and operating system
