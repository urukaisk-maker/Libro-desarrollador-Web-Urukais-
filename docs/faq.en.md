## 🏠 About the Project

??? question "What is the Web Developer's Book exactly?"
    It is a **free, open-source educational resource** that teaches web development from scratch to an advanced level. It is structured into **7 levels** and **38 chapters**, including theory, runnable examples, solved exercises, interactive quizzes, and an achievement system.

    It's not a paid course or a subscription platform: it's an open book you can read, copy, and reuse freely.

??? question "Who is behind the project?"
    The project is maintained by **Manuel Casimiro Carrasco (Urukais)**, web developer and technical writer. You can learn more on the [About the Author](autor.md) page.

??? question "Why is it free?"
    When I started learning, there wasn't enough open material without paywalls or awkward machine translations. I wanted anyone—regardless of financial situation—to be able to learn how to code. The book has no ads, no affiliates, and no paywalls. If you want to [support the project](apoya.md), you're welcome to, but it's never required.

??? question "How is it funded?"
    **With the author's free time and community support.** Infrastructure (GitHub Pages, GitHub Actions) is free. Any support via [Substack](https://urukaisklick.substack.com) or [support](apoya.md) goes back into the project or a thank-you coffee.

??? question "How long has it been published?"
    The project launched publicly in **October 2026**. Since then, it has been updated regularly with new chapters, design improvements, and extra resources.

??? question "Does it have an end date?"
    **No.** The project is a marathon, not a sprint. Chapters are published when they're ready, not on a forced rush. I'd rather have one well-crafted chapter a month than a rushed one every week.

## 📚 About the Content

??? question "Who is this book for?"
    Mainly for **three profiles**:

    - **Complete beginners**: people who have never written a line of code.
    - **Students and self-taught learners**: looking for structured reference material.
    - **Developers in transition**: who already code and want to go deeper or modernize their skills.

    It's not a narrow reference for specialists; while higher levels cover advanced topics, the approach is pedagogical and progressive.

??? question "In what order should I read the chapters?"
    **In order**, especially if you're just starting out. Each chapter builds on the previous one. If you already have experience, you can jump straight to the right level using the **🗂 Explore** menu at the top.

??? question "How is it different from other books or courses?"
    Three main things:

    1. **Written from scratch with clear explanations**, not machine-translated filler.
    2. **Free and open source**, with no ads or subscriptions.
    3. **Interactive learning tools** (quizzes, live editors, achievement system) that static books don't offer.

??? question "Can I use the content to teach classes?"
    **Yes**, as long as you keep attribution and don't sell it as your own. The MIT license lets you use, copy, and modify the content. Feel free to [message me](contacto.md) to share how you use it—I'd love to hear.

??? question "Is the content kept up to date?"
    **Yes.** The book is reviewed periodically as the web ecosystem evolves. You can check updates in the [Changelog](changelog.md). If you spot outdated info, [open an issue](https://github.com/urukaisk-maker/Libro-desarrollador-Web-Urukais-/issues/new).

??? question "Does it cover frameworks like React, Vue, or Angular?"
    It covers the **fundamentals** (HTML, CSS, JavaScript) and the core concepts **behind** frameworks. It doesn't dive deep into any single framework because frameworks come and go, while fundamentals remain.

    In the [Advanced Level](capitulos/11-css-moderno.md) there are chapters on modules, bundlers, and architecture that prepare you to pick up any framework afterward.

??? question "Does it include backend?"
    **Yes.** The [Professional Level](capitulos/19-fullstack-node.md) covers Full-stack with Node.js and DevOps for frontend. It's not frontend-only.

??? question "Does it include exercises and projects?"
    **Yes.** Each chapter includes:

    - Runnable examples
    - Practice exercises
    - An interactive quiz
    - In some cases, a guided project

    You also have the [Solved Exercises](ejercicios/index.md) section with over 30 annotated solutions.

## 🛠 About the Tech Stack

??? question "Can I follow the book without installing anything?"
    **Yes**, the early chapters can be followed right in your browser using the live editors on each page. Only when you reach Node.js or backend topics will you need to install tools on your machine.

??? question "Which code editor do you recommend?"
    [**VS Code**](https://code.visualstudio.com/) is the most popular and the one I use in examples. You can also try [**Zed**](https://zed.dev/), [**Sublime Text**](https://www.sublimetext.com/), or [**Neovim**](https://neovim.io/) if you prefer something faster or more customizable.

??? question "Does it work on Windows, macOS, and Linux?"
    **Yes.** The book is a website, so it works on any OS. Terminal commands focus on **Linux/macOS** (most common in web dev), while on Windows you can use **WSL** or **PowerShell** with minor adjustments.

??? question "Do I need a powerful computer?"
    **No.** For 90% of the book, almost any computer from the last 10 years works fine. Only for Docker and certain backend tools will you want at least 8 GB of RAM.

??? question "Can I use a phone or tablet?"
    **Yes**, the site is responsive and works on any device. For coding, though, a physical keyboard is strongly recommended.

??? question "Which browser do I need?"
    Any modern browser: up-to-date **Chrome, Firefox, Edge, or Safari**. It won't target Internet Explorer.

## 🎓 About Learning

??? question "How long does it take to finish the book?"
    It depends on your pace and prior experience. As a rough guide:

    - **Full-time** (4–6 h/day): 3–4 months
    - **Steady pace** (1–2 h/day): 8–12 months
    - **Light pace** (2–3 h/week): 2–3 years

    Speed matters less than consistency.

??? question "Do I need strong math skills?"
    **No**, for 95% of the book you only need basic arithmetic. Math only shows up in specific advanced areas (WebGL, cryptography, WebAssembly), where it's explained from scratch.

??? question "Do I need to know English?"
    **Not strictly required to start**, though **strongly recommended**. Most technical docs, articles, and Stack Overflow answers are in English. Key terms are explained as they come up, and as you advance you'll benefit from reading English documentation.

    > *"English is the lingua franca of programming. You don't need to speak it fluently on day one, but you do need to read it."*

??? question "Can I learn to code with this book alone?"
    **Yes, with a caveat.** The book gives you theory, examples, and exercises. **Learning to program takes practice**: building your own projects, making mistakes, debugging, reading other people's code. The book is a map, not a shortcut.

??? question "How can I tell if I'm making progress?"
    - **Achievement system**: completing a chapter unlocks a badge.
    - **Quizzes**: at the end of each chapter, you test what you've learned.
    - **Solved exercises**: compare your solution against the reference one.
    - **Personal projects**: the clearest sign is building something on your own without following a step-by-step tutorial.

??? question "What should I do when I get stuck?"
    1. **Re-read** the chapter calmly.
    2. **Search** the error on Google or [Stack Overflow](https://stackoverflow.com/).
    3. **Ask** the community on [GitHub Discussions](https://github.com/urukaisk-maker/Libro-desarrollador-Web-Urukais-/discussions).
    4. **Take a break**: stepping away for 10 minutes often clears things up.

    !!! tip "Tip"
        When stuck, try explaining the problem out loud (or in writing). **Rubber duck debugging** works because walking through the problem often reveals the solution.

??? question "How can I practice more?"
    - Do the exercises in each chapter.
    - Tackle the [weekly challenges](retos.md).
    - Build personal projects (a portfolio, a to-do app, a blog…).
    - Contribute to open-source projects (including this one).
    - Read other developers' code on GitHub.

## 🏆 About Achievements & Certificate

??? question "How does the achievement system work?"
    When you finish a chapter, you check the box at the bottom of the page. A badge unlocks and is saved in your browser via `localStorage`. You can view your progress on the [My Achievements](logros.md) page.

??? question "Are achievements stored on a server?"
    **No.** Everything is stored **in your browser**. Nothing is sent to a server. Clearing your browser storage resets your achievements.

??? question "Can I sync achievements across devices?"
    **Not yet.** It's on the [Roadmap](roadmap.md), but requires an authentication system that isn't implemented yet.

??? question "Is the certificate officially accredited?"
    **No.** The certificate is a **symbolic recognition** that you completed the book. It has no official academic or professional accreditation, though you can add it to your portfolio or LinkedIn as proof of self-directed study.

??? question "How do I get the certificate?"
    Once you complete all chapters in the book, you'll unlock the option to generate your certificate on the [Certificate](certificado.md) page, downloadable as a PDF with your name and completion date.

## 🤝 About Contributing

??? question "Can I contribute if I don't know how to code?"
    **Yes.** There are plenty of ways to contribute without writing code: reporting typos, suggesting improvements, sharing the book, translating sections. Everything helps. See the [Contribute](contribuir.md) page for details.

??? question "How do I report a bug?"
    Open an [issue on GitHub](https://github.com/urukaisk-maker/Libro-desarrollador-Web-Urukais-/issues/new) with:

    - What you expected to happen
    - What actually happened
    - Steps to reproduce it
    - Your environment (browser, operating system)

??? question "Can I translate the book into another language?"
    **Yes**, we're actively working on English localization with `mkdocs-static-i18n`. If you'd like to help, open an issue with the `i18n` label and let us know which language interests you.

??? question "Do I get paid to contribute?"
    **No.** This is a volunteer open-source project. What you gain is experience, visibility, and the satisfaction of helping others learn. Contributors are recognized on the [Acknowledgements](agradecimientos.md) page.

## 🌐 About the Website

??? question "Why does the site sometimes take a moment to load?"
    The first visit may take a couple of seconds to load fonts, styles, and scripts. After that, navigation feels instant thanks to Material's instant loading/prefetching.

??? question "Does it work offline?"
    **Partially.** The book is configured as a **PWA** (Progressive Web App), so once visited, some pages are cached for offline reading. Not every interactive feature works offline.

??? question "Can I read the book on a Kindle or e-reader?"
    **Yes**, using the [printable version](../print_page/) you can generate a PDF or EPUB to send to your e-reader. Keep in mind interactive quizzes and live editors won't run inside an e-reader.

??? question "Is there a PDF version?"
    **Yes.** You can generate the printable view from the [Printable version](../print_page/) link, which combines chapters onto a single page that you can save as PDF from your browser.

??? question "How do I report a website issue?"
    If something looks off (a broken link, layout glitch, console error), open an [issue on GitHub](https://github.com/urukaisk-maker/Libro-desarrollador-Web-Urukais-/issues/new) with:

    - The page URL
    - A screenshot
    - Your browser and operating system
