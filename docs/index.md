## 🚀 El Viaje del Desarrollador

<div class="grid cards" markdown>

-   ![Nivel 1](img/1.jpg)

    **Nivel 1: Principiante**

    HTML, CSS, JavaScript, responsive y formularios.

    [:octicons-arrow-right-24: Empezar el viaje](capitulos/01-introduccion.md)

-   ![Nivel 2](img/2.jpg)

    **Nivel 2: Intermedio**

    Git, APIs, despliegue y portfolio.

    [:octicons-arrow-right-24: Subir de nivel](capitulos/07-git.md)

-   ![Nivel 3](img/3.jpg)

    **Nivel 3: Avanzado**

    CSS moderno, JS asíncrono, TypeScript, testing.

    [:octicons-arrow-right-24: Explorar la técnica](capitulos/11-css-moderno.md)

-   ![Nivel 4](img/4.png)

    **Nivel 4: Profesional**

    Full-stack con Node.js y DevOps.

    [:octicons-arrow-right-24: Pensar como pro](capitulos/19-fullstack-node.md)

-   ![Nivel 5](img/5.png)

    **Nivel 5: Experto**

    Web Components, PWA, WebSockets, design systems.

    [:octicons-arrow-right-24: Crear experiencias](capitulos/21-web-components.md)

-   ![Nivel 6](img/6.jpg)

    **Nivel 6: Élite**

    Seguridad, WebAssembly, IA, WebXR, Web3.

    [:octicons-arrow-right-24: Romper límites](capitulos/26-seguridad.md)

-   ![Nivel 7](img/7.jpg)

    **Nivel 7: Vanguardia**

    Testing E2E, Server Components, Edge, Docker, GraphQL.

    [:octicons-arrow-right-24: Ir al futuro](capitulos/31-testing-e2e.md)

</div>
