## 🎤 ¿Quieres que dé una charla o taller?

Si organizas un meetup, una conferencia o un taller y te interesa que participe, escríbeme a [contacto@urukais.com](mailto:contacto@urukais.com) con los detalles:

- **Evento**: nombre y temática
- **Formato**: charla, taller, mesa redonda…
- **Duración**: 20 min, 1 h, 2 h…
- **Público objetivo**: principiantes, intermedios, expertos
- **Fecha y lugar**: presencial u online
- **Presupuesto**: si lo hay, para cubrir desplazamiento

!!! tip "Temas en los que puedo hablar"
    - Fundamentos de la web (HTML, CSS, JavaScript)
    - JavaScript moderno (ES6+, async/await, event loop)
    - Accesibilidad web desde cero
    - Arquitectura frontend
    - Cómo crear un libro open source (mi experiencia con este proyecto)

---

## 🎯 ¿Quieres proponer un evento?

Si tienes una idea para un taller, un directo o una charla, puedes proponerla:

1. **Abre un issue** en GitHub con la etiqueta `evento`:
   [Proponer evento](https://github.com/urukaisk-maker/Libro-desarrollador-Web-Urukais-/issues/new)
2. **Rellena la plantilla** con:
   - Título del evento
   - Descripción breve
   - Formato (online/presencial)
   - Público objetivo
   - Fecha propuesta
   - Si necesitas colaboración o recursos

Los eventos propuestos se revisan cada semana. Si encajan con el proyecto, se añaden a la agenda.

## ❓ Preguntas frecuentes

??? question "¿Los eventos son gratuitos?"
    **Sí, todos los eventos son gratuitos.** No hay eventos de pago, ni "versiones premium" de los talleres. Si algún día hay un evento con coste (por ejemplo, un taller presencial con materiales), se indicará claramente.

??? question "¿Qué necesito para asistir a un taller?"
    Depende del taller. Para los talleres online, solo necesitas un navegador y ganas de aprender. Para los presenciales, se indica en la descripción del evento.

??? question "¿Se graban los eventos?"
    **Sí, la mayoría.** Los talleres y charlas se graban y se publican en YouTube para que puedas verlos cuando quieras. Los directos de Twitch se quedan en el canal durante un tiempo limitado.

??? question "¿Puedo proponer un tema para un taller?"
    **Sí.** Abre un issue con la etiqueta `evento` y dinos qué tema te interesa. Si tiene suficiente demanda, se programa.

??? question "¿Cómo me entero de los nuevos eventos?"
    - **Newsletter**: suscríbete en [Substack](https://urukaisklick.substack.com).
    - **Twitter / X**: sigue a [@urukaisk](https://twitter.com/urukaisk).
    - **GitHub**: mira los issues con la etiqueta `evento`.
