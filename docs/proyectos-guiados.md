# 🧭 Proyectos Guiados

!!! quote "Aprender construyendo"
    Los proyectos guiados son **tutoriales paso a paso** para construir aplicaciones reales. Cada uno está pensado para aplicar lo que has aprendido en los capítulos, con explicaciones detalladas y código completo.

---

## 🎯 ¿Qué es un proyecto guiado?

Un proyecto guiado no es un ejercicio suelto: es una **aplicación completa** que construyes desde cero, con:

| Elemento | Descripción |
| :--- | :--- |
| 🎯 **Objetivo claro** | Qué vas a construir y por qué |
| 📋 **Requisitos previos** | Qué capítulos necesitas haber leído |
| 📁 **Estructura** | Cómo organizar los archivos |
| 🔹 **Paso a paso** | Cada paso explicado con código |
| ✅ **Código final** | El proyecto completo, listo para copiar |
| 🚀 **Retos extra** | Ideas para ampliarlo cuando termines |

!!! tip "¿Cómo usarlos?"
    1. Lee primero el objetivo del proyecto.
    2. Comprueba que tienes los conocimientos previos.
    3. Sigue los pasos **sin copiar y pegar** (escribe el código tú mismo).
    4. Si te atascas, consulta el código final.
    5. Cuando termines, intenta los retos extra.

## 🎮 Proyecto: El Niño { #proyecto-el-nino }

**Nivel**: 🟠 Avanzado
**Tecnologías**: HTML5 Canvas, JavaScript, Web Audio API
**Tiempo estimado**: 6–8 horas
**Demo**: [https://plataforma-el-ni-o.vercel.app/](https://plataforma-el-ni-o.vercel.app/)

### 🎯 Objetivo

Construir un **juego de plataformas 2D** con:

- Física básica (gravedad, salto, colisiones)
- Sistema de niveles
- Enemigos y obstáculos
- Sonido con Web Audio API
- Puntuación y vidas
- Pantalla de inicio y game over

!!! info "Proyecto real y funcional"
    Este proyecto está **desplegado y funcionando** en [plataforma-el-ni-o.vercel.app](https://plataforma-el-ni-o.vercel.app/). Puedes jugarlo antes de construirlo para ver el resultado final.

### 🎮 ¿Qué es El Niño?

**El Niño** es un juego de plataformas 2D donde controlas a un personaje que debe superar niveles llenos de obstáculos, enemigos y plataformas móviles. El objetivo es llegar al final de cada nivel recogiendo monedas y evitando caer al vacío.

### 🛠️ Stack técnico

| Tecnología | Uso |
| :--- | :--- |
| **HTML5 Canvas** | Renderizado del juego a 60 FPS |
| **JavaScript (ES6+)** | Lógica del juego, física y controles |
| **Web Audio API** | Efectos de sonido y música |
| **CSS3** | Interfaz de usuario (menús, HUD) |
| **Vercel** | Despliegue y hosting |
