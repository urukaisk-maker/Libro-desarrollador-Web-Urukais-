# Introducción

Bienvenido al **Libro del Desarrollador Web**. Este material te llevará desde cero hasta construir aplicaciones web completas.

## ¿Para quién es este libro?

- Personas que quieren iniciarse en el desarrollo web.
- Estudiantes que buscan material de referencia.
- Autodidactas que prefieren aprender con ejemplos prácticos.

## ¿Qué vas a aprender?

1. Fundamentos de HTML y CSS.
2. JavaScript moderno (ES6+).
3. Estructura de proyectos web.
4. Buenas prácticas y accesibilidad.
5. Despliegue y publicación de sitios.

## Cómo leer este libro

Sigue los capítulos en orden. Cada uno incluye teoría, ejemplos en la carpeta `ejemplos/` y ejercicios propuestos.
