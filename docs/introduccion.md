# 👋 Bienvenido al Libro del Desarrollador Web

!!! quote "De cero a Silicon Valley"
    Este libro nace con una idea simple: **cualquiera puede aprender a programar** si tiene una guía clara, ejemplos reales y ganas de practicar. No necesitas un título, ni un equipo caro, ni un curso de pago. Solo un navegador, un editor de texto y constancia.

Te acompañaremos desde tu primera etiqueta HTML hasta las arquitecturas más avanzadas del desarrollo moderno: TypeScript, Web Components, PWA, Edge Computing, IA generativa y más.

---

## 🎯 ¿Para quién es este libro?

Este material está pensado para **tres perfiles** muy concretos:

| Perfil | Lo que encontrarás aquí |
| :--- | :--- |
| 🌱 **Principiante absoluto** | Explicaciones desde cero, sin asumir conocimientos previos. Cada concepto se introduce con ejemplos ejecutables. |
| 🎓 **Estudiante o autodidacta** | Material de referencia estructurado en 7 niveles, con ejercicios resueltos y retos semanales. |
| 🔄 **Profesional en transición** | Capítulos avanzados sobre arquitectura, testing, rendimiento y despliegue en producción. |

!!! tip "¿No sabes por dónde empezar?"
    Si es tu primera vez programando, ve directo al [Nivel Principiante](capitulos/01-introduccion.md). Si ya tienes experiencia, salta al nivel que corresponda a tu conocimiento actual con el botón **🗂️ Explorar** del menú superior.

---

## 📚 ¿Qué vas a aprender?

El libro está dividido en **7 niveles progresivos** y **38 capítulos**, diseñados para que avances sin perderte:

=== "🟢 Fundamentos"

    - **HTML5** semántico y accesible
    - **CSS3** moderno: Flexbox, Grid, variables, animaciones
    - **JavaScript** esencial: variables, funciones, DOM, eventos
    - **Diseño responsive** con media queries y mobile-first
    - **Formularios** HTML y validación nativa

=== "🟡 Intermedio"

    - **Git y GitHub**: control de versiones y trabajo en equipo
    - **APIs REST** con `fetch` y `async/await`
    - **Despliegue** en Netlify, Vercel, GitHub Pages
    - **Tu primer portfolio** profesional

=== "🟠 Avanzado"

    - **CSS moderno**: container queries, `:has()`, subgrid
    - **JavaScript asíncrono** en profundidad: promesas, event loop
    - **Módulos** ES6 y bundlers (Vite, esbuild)
    - **TypeScript** desde cero
    - **Testing** con Vitest y Testing Library
    - **Accesibilidad** WCAG y ARIA

=== "🔴 Profesional"

    - **Full-stack con Node.js**: Express, bases de datos, autenticación
    - **DevOps para frontend**: CI/CD, Docker, monitorización

=== "🟣 Experto"

    - **Web Components** nativos
    - **PWA** con service workers
    - **WebSockets** y tiempo real
    - **Animaciones** avanzadas con GSAP y Framer Motion
    - **Design systems** escalables

=== "🔵 Élite"

    - **Seguridad web**: XSS, CSRF, CSP, CORS
    - **WebAssembly** en el navegador
    - **IA en el frontend** con TensorFlow.js
    - **WebXR** para realidad aumentada y virtual
    - **Web3** y blockchain

=== "🚀 Vanguardia"

    - **Testing E2E** con Playwright
    - **React Server Components**
    - **Edge Computing** con Cloudflare Workers
    - **Docker** para frontend
    - **GraphQL** y **micro-frontends**
    - **IA generativa** aplicada al desarrollo

## 🛠️ ¿Qué necesitas para empezar?

Solo tres cosas, todas gratis:

1. **Un navegador moderno** (Chrome, Firefox, Edge o Safari actualizado)
2. **Un editor de código**: recomendamos [VS Code](https://code.visualstudio.com/) o [Zed](https://zed.dev/)
3. **Muchas ganas de practicar** 💪

!!! note "No necesitas instalar nada para empezar"
    Los primeros capítulos se pueden seguir directamente en el navegador, con los **editores en vivo** que encontrarás en cada página. Solo cuando llegues a Node.js necesitarás instalar cosas en tu equipo.
