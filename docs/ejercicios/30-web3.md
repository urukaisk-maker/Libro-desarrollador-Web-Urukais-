# 30 — Web3

!!! quote "Ejercicio resuelto"
    Conecta con MetaMask y lee la cuenta del usuario.

---

## 🎯 Objetivo

1. Detecta si MetaMask está instalado.
2. Pide permiso para conectar.
3. Muestra la dirección de la wallet.

---

## 💡 Solución

\`\`\`html
<button id="conectar">Conectar wallet</button>
<p id="cuenta"></p>

<script>
  document.getElementById('conectar').addEventListener('click', async () => {
    if (!window.ethereum) {
      alert('Instala MetaMask');
      return;
    }

    try {
      const cuentas = await window.ethereum.request({
        method: 'eth_requestAccounts'
      });
      document.getElementById('cuenta').textContent =
        'Conectado: ' + cuentas[0];
    } catch (err) {
      console.error('Error:', err);
    }
  });
</script>
\`\`\`

---

## 🧠 Conceptos clave

- \`window.ethereum\`: inyectado por MetaMask.
- \`eth_requestAccounts\`: pide permiso.
- Direcciones Ethereum: 0x + 40 caracteres hexadecimales.
