# 30 — Web3

!!! quote "Solved exercise"
    Connect to MetaMask and read the user account.

---

## 🎯 Goal

1. Detect whether MetaMask is installed.
2. Request permission to connect.
3. Display the wallet address.

---

## 💡 Solution

```html
<button id="conectar">Connect wallet</button>
<p id="cuenta"></p>

<script>
  document.getElementById('conectar').addEventListener('click', async () => {
    if (!window.ethereum) {
      alert('Install MetaMask');
      return;
    }

    try {
      const cuentas = await window.ethereum.request({
        method: 'eth_requestAccounts'
      });
      document.getElementById('cuenta').textContent =
        'Connected: ' + cuentas[0];
    } catch (err) {
      console.error('Error:', err);
    }
  });
</script>
```

---

## 🧠 Key concepts

- `window.ethereum`: injected by MetaMask.
- `eth_requestAccounts`: requests permission.
- Ethereum addresses: 0x + 40 hexadecimal characters.
