## 🌐 ¿Qué es Web3?

**Web3** es una visión descentralizada de la web basada en **blockchain**. En lugar de que los datos estén en servidores de empresas (Web2), están distribuidos en una red peer-to-peer.

```
Web1 (1990s)  → solo lectura (webs estáticas)
Web2 (2000s)  → lectura y escritura (redes sociales, apps)
Web3 (futuro) → lectura, escritura y propiedad (blockchain)
```

!!! quote "Web3 no es solo criptomonedas"
    Aunque las criptomonedas son la aplicación más famosa, Web3 también incluye identidad descentralizada, almacenamiento distribuido y gobernanza comunitaria.

---

## ⛓️ ¿Qué es una blockchain?

Una **blockchain** es un registro distribuido e inmutable de transacciones. Cada bloque contiene un hash del anterior, formando una cadena.

```
Bloque 1 → Bloque 2 → Bloque 3 → ...
   hash       hash       hash
```

| Característica | Descripción |
| :--- | :--- |
| **Descentralizada** | No hay un servidor central |
| **Inmutable** | Los datos no se pueden modificar |
| **Transparente** | Cualquiera puede ver las transacciones |
| **Pseudoanónima** | Las direcciones no revelan identidad |

## 👛 Wallets

Una **wallet** es una aplicación que guarda tus claves privadas y te permite interactuar con la blockchain.

| Wallet | Tipo |
| :--- | :--- |
| **MetaMask** | Extensión de navegador |
| **Rabby** | Extensión de navegador |
| **WalletConnect** | Móvil, conexión con dApps |
| **Coinbase Wallet** | Móvil + extensión |
| **Ledger** | Hardware |

```javascript
// Conectar MetaMask
if (window.ethereum) {
  const cuentas = await window.ethereum.request({
    method: "eth_requestAccounts"
  });
  console.log("Conectado:", cuentas[0]);
}
```

## 📜 Smart contracts

Un **smart contract** es un programa que se ejecuta en la blockchain. Una vez desplegado, no se puede modificar.

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

contract Contador {
    uint256 public valor;

    function incrementar() public {
        valor += 1;
    }

    function decrementar() public {
        require(valor > 0, "No puede ser negativo");
        valor -= 1;
    }
}
```

```bash
npx hardhat run scripts/deploy.js --network sepolia
```

## 🎯 Casos de uso reales

| Caso | Descripción |
| :--- | :--- |
| **DeFi** | Finanzas descentralizadas (préstamos, exchanges) |
| **NFTs** | Tokens únicos (arte digital, coleccionables) |
| **DAOs** | Organizaciones autónomas descentralizadas |
| **Identidad** | Identidad auto-soberana (SSI) |
| **Supply chain** | Trazabilidad de productos |
| **Juegos** | Play-to-earn, activos in-game |

---

## ⚠️ Limitaciones

- **Escalabilidad**: las blockchains son lentas comparadas con Web2.
- **Coste**: las transacciones en Ethereum pueden costar mucho (gas).
- **Experiencia de usuario**: las wallets son complicadas para no expertos.
- **Regulación**: el marco legal es incierto en muchos países.
- **Seguridad**: los bugs en smart contracts son irreversibles.
- **Especulación**: mucha gente usa Web3 para especular, no para construir.
