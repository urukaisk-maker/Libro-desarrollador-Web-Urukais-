# Capítulo 33 — Edge Computing

## Introducción

Tradicionalmente, todo tu código vivía en un servidor central (por ejemplo, en Virginia, EE. UU.). Si un usuario accedía desde España, su petición viajaba hasta Virginia, se procesaba y volvía.

El **Edge Computing** consiste en ejecutar el código **lo más cerca posible del usuario**, en nodos distribuidos por todo el mundo. La latencia se reduce drásticamente (de 200ms a 20ms).

## ¿Qué es el Edge?

Plataformas como **Vercel, Cloudflare, Netlify o Deno Deploy** tienen centros de datos en cientos de ciudades. Cuando alguien visita tu web, el código se ejecuta en el nodo más cercano.
