# Capítulo 1 — Introducción al desarrollo web

## ¿Qué es el desarrollo web?

El desarrollo web es el proceso de crear sitios y aplicaciones que se ejecutan en el navegador. Combina estructura (HTML), estilo (CSS) y comportamiento (JavaScript).

## Frontend vs Backend

| Aspecto | Frontend | Backend |
|---|---|---|
| Se ejecuta en | Navegador | Servidor |
| Lenguajes | HTML, CSS, JS | Node, Python, PHP |
| Responsabilidad | Interfaz de usuario | Lógica y datos |
