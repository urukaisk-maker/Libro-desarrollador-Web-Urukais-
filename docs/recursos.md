# Recursos

Material adicional para seguir aprendiendo desarrollo web.

## 📖 Documentación oficial

- [MDN Web Docs](https://developer.mozilla.org/es/) — la referencia definitiva para HTML, CSS y JavaScript.
- [HTML Living Standard](https://html.spec.whatwg.org/) — el estándar vivo de HTML.
- [CSS Tricks](https://css-tricks.com/) — artículos y trucos de CSS.
- [JavaScript.info](https://es.javascript.info/) — tutorial moderno de JavaScript en español.

## 🛠️ Herramientas recomendadas

- [Visual Studio Code](https://code.visualstudio.com/) — editor gratuito y extensible.
- [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) — extensión de VS Code que recarga la página al guardar.
- [Figma](https://www.figma.com/) — diseño y prototipado.
- [Can I use](https://caniuse.com/) — compatibilidad de características web por navegador.

## 🎓 Cursos gratuitos

- [freeCodeCamp](https://www.freecodecamp.org/espanol/)
- [The Odin Project](https://www.theodinproject.com/)
- [Learn CSS — web.dev](https://web.dev/learn/css/)

## 📚 Libros recomendados

- *HTML and CSS: Design and Build Websites* — Jon Duckett
- *Eloquent JavaScript* — Marijn Haverbeke
- *CSS: The Definitive Guide* — Eric A. Meyer

## 🧩 Prácticas

- [Frontend Mentor](https://www.frontendmentor.io/) — retos de diseño reales.
- [CSSBattle](https://cssbattle.dev/) — retos de CSS creativos.
- [Exercism](https://exercism.org/) — ejercicios con mentoría.
